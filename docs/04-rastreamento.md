# Rastreamento de pedidos – Loja NovaTech

## Onde acompanhar
O código de rastreio é enviado por e-mail quando o pedido sai do centro de distribuição. Ele também aparece na área "Meus pedidos".

## Status do pedido
| Status | O que significa |
| --- | --- |
| Aguardando pagamento | O pagamento ainda não foi confirmado |
| Pagamento aprovado | O pedido está sendo separado |
| Em transporte | O pedido saiu do centro de distribuição |
| Saiu para entrega | O pedido está com o entregador hoje |
| Entregue | O pedido foi recebido |

## Pedido atrasado
Se o prazo de entrega passou e o status não mudou há mais de 3 dias úteis, o cliente deve abrir um chamado em "Meus pedidos > Preciso de ajuda". A NovaTech responde em até 1 dia útil.
